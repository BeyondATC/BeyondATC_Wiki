# What to Say: Quick Reference

Each of these also exists as a button. Saying the full phrase skips the button sub-menu.

| You want | Say |
|---|---|
| Taxi for pattern work | *"Request taxi for closed traffic"* (US) / *"…for circuits"* (UK/AU) |
| Taxi for a departure | *"Request taxi for VFR departure"* |
| Flight following (US/AU) | *"Request flight following to {destination}"* |
| Basic / Traffic Service (UK) | *"Request basic service"* / *"Request traffic service"* |
| Class B/C departure clearance (US) | *"{Clearance}, {callsign}, {type}, with information {ATIS}, VFR to {destination}"* |
| Airspace transition (US) | *"Request transition through the Class {Bravo/Charlie/Delta}"* |
| Zone transit (UK/AU) | *"Request zone transit"* → details on "pass your message" |
| Airways clearance (AU Class C) | *"Request airways clearance"* |
| Join the circuit | *"Report inbound"* (US) / *"Request join"* (UK/AU) |
| Circuit report | *"Downwind runway 27, touch and go"* (US) / *"Downwind"* (UK/AU) |
| Traffic response | *"Traffic in sight"* or *"visual"* / *"Looking for traffic"* (radar services also accept *"negative contact"*) |
| Go around | *"Going around"* |
| Cancel a service | *"Cancel flight following"* / *"Service no longer required"* |
| Leave a frequency | *"Request frequency change"* / *"Changing to {station}"* |
| Uncontrolled field | Announce in the blind, *"{Field} traffic, {callsign}, …, {field}"* |
