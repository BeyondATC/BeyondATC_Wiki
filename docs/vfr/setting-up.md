# Setting Up Your Flight

## Using the MSFS World Map

BeyondATC can automatically import a flight plan you set up in the MSFS world map:

!!! warning "Important"
    When using the MSFS world map option, you must set both your departure and destination airport.

1. Set your departure and destination airports in the MSFS world map
2. Load into the sim

!!! tip "Practicing Circuit Flights?"
    You can set the same airport as both departure and destination, especially useful for circuit practice.

## Using a .PLN or .LNMPLN File

You can import flight plan files (.pln or .lnmpln) generated by the sim and tools like Little NavMap. Select **VFR** on the BeyondATC main menu and choose the file import option.

## Using SimBrief

SimBrief plans can also be loaded. For most VFR flights, you only need to set the departure and destination airports; routes and procedures are currently not used. Make sure you set your flight rules to **VFR** in SimBrief.

!!! info "Note"
    The BeyondATC main menu has separate **IFR** and **VFR** sections. When selecting VFR you choose your import method (MSFS, file, or SimBrief) before loading. A flight plan is still required (BeyondATC uses it to spawn traffic efficiently), but a VFR flight is not bound to it: you can divert or explore freely, and airports load dynamically when you approach them.
