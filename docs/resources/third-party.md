# Third-Party Apps & Add-ons

The flight sim community has built some great tools that work alongside BeyondATC. This page collects the ones we know about, so you can find them in one place.

!!! danger "Please read before installing anything from this page"
    Everything listed here is made by **independent third-party developers**. BeyondATC does not develop, maintain, review, or have any control over these apps and add-ons.

    - **No support from BeyondATC.** We cannot help with installing, configuring, or troubleshooting third-party software. Please contact the author directly, using the link on each entry.
    - **Use at your own risk.** BeyondATC is not responsible for any malware, data loss, system instability, simulator problems, or any other harm caused by installing or using third-party software.
    - **Not an endorsement.** Being listed here does not mean we have tested, approved, or vouch for an app, its safety, or its author.
    - **Updates can break things.** A BeyondATC or simulator update may stop a third-party tool from working. Only its author can fix that.

    Only download from the author's official page, and scan anything you download before you run it.

!!! tip "Reporting a BeyondATC bug?"
    Before you [report a bug](../support/bug-reporting.md), turn off or uninstall any third-party tools and check that the problem still happens. This helps us make sure the problem is in BeyondATC and not in an add-on.

## BeyondATC Mobile Bridge

Follow your ATC conversation from a phone or tablet over Wi-Fi. Mobile Bridge shows the ATC log and lets you change frequencies, reply to ATC and request clearances. It also has a live moving map with airport layouts and taxi routes. It runs in your device's web browser, so you don't need to install an app on your phone.

**Author:** maestro_it · **Support:** via the author's flightsim.to page

## Beyond ATC LOG Scanner

A standalone Windows app that reads your BeyondATC log files so you can look back over a flight. It colour-codes the ATC communications and shows vectoring decisions, METAR data and speech recognition results, which can help you see why ATC didn't understand a particular call.

**Author:** WilbikFS · **Support:** via the author's flightsim.to page

<a class="tp-preview" href="https://flightsim.to/addon/75707/beyond-atc-log-scanner" target="_blank" rel="noopener nofollow">
  <span class="tp-preview__site">flightsim.to</span>
  <span class="tp-preview__title">Beyond ATC LOG Scanner</span>
  <span class="tp-preview__desc">Review a flight's ATC communications, vectors, METARs and speech recognition from your BeyondATC logs.</span>
  <span class="tp-preview__url">flightsim.to/addon/75707/beyond-atc-log-scanner</span>

## BeyondATC Airport Profiles (community collection)

Community-made patches for airport scenery that help those airports work better with BeyondATC, for example by fixing runway hold-short lines, taxi routing and taxiway names. Each profile is made by a different author and only applies to a specific airport, and sometimes to a specific scenery package. Read each add-on's description to check which scenery it needs.

**Authors:** various · **Support:** via each add-on's own flightsim.to page

<a class="tp-preview" href="https://flightsim.to/miscellaneous/beyondatc-profiles" target="_blank" rel="noopener nofollow">
  <span class="tp-preview__site">flightsim.to</span>
  <span class="tp-preview__title">BeyondATC Profiles</span>
  <span class="tp-preview__desc">A collection of airport mods that improve hold-short points, taxi routing and taxiway names for BeyondATC.</span>
  <span class="tp-preview__url">flightsim.to/miscellaneous/beyondatc-profiles</span>
</a>

## Robins Airport Frequency Fixes

Corrects outdated or missing ATC frequencies at selected third-party airport sceneries. BeyondATC uses the frequencies that your airport scenery provides, so wrong frequencies in a scenery package show up as wrong frequencies in BeyondATC. This add-on fixes them for the airports it covers. Check the add-on's page for the list of airports and the scenery each fix is for.

**Author:** afireinside1988 · **Support:** via the author's flightsim.to page

<a class="tp-preview" href="https://flightsim.to/addon/113020/robins-airport-frequency-fixes" target="_blank" rel="noopener nofollow">
  <span class="tp-preview__site">flightsim.to</span>
  <span class="tp-preview__title">Robins Airport Frequency Fixes</span>
  <span class="tp-preview__desc">Updates outdated or missing ATC frequencies for selected third-party airports in MSFS.</span>
  <span class="tp-preview__url">flightsim.to/addon/113020/robins-airport-frequency-fixes</span>
</a>

## Garmin 3000/5000 CPDLC and SimBrief

Adds CPDLC to aircraft with the Garmin G3000/G5000 avionics, so you can use [BeyondATC's CPDLC](../knowledge-base/cpdlc.md) in aircraft that don't come with it. It also adds SimBrief weight and balance import. Check the add-on's page for the list of supported aircraft.

**Author:** liz3 · **Support:** via the author's flightsim.to page

<a class="tp-preview" href="https://flightsim.to/file/98506/garmin-3000-5000-cpdlc-and-simbrief" target="_blank" rel="noopener nofollow">

  <span class="tp-preview__desc">Adds Hoppie, SayIntentions and BeyondATC CPDLC, plus SimBrief weight and balance import, to the G3000/G5000.</span>
  <span class="tp-preview__url">flightsim.to/file/98506/garmin-3000-5000-cpdlc-and-simbrief</span>

## FSLTL (FS Live Traffic Liveries)

A free library of AI aircraft models and airline liveries. BeyondATC can use FSLTL models for the [traffic it injects](../knowledge-base/live-traffic.md). You only need the models installed. You don't need to run the FSLTL injector alongside BeyondATC.

**Author:** the FSLTL team · **Support:** via the FSLTL website and community

<a class="tp-preview" href="https://fslivetrafficliveries.com/" target="_blank" rel="noopener nofollow">
  <span class="tp-preview__site">fslivetrafficliveries.com</span>
  <span class="tp-preview__title">FSLTL - FS Live Traffic Liveries</span>
  <span class="tp-preview__desc">Free AI traffic models and thousands of airline liveries for Microsoft Flight Simulator.</span>
  <span class="tp-preview__url">fslivetrafficliveries.com</span>
</a>

## AIG (Alpha India Group)

A long-running community project that publishes AI traffic models and liveries, installed and updated with the AIG AI Manager. BeyondATC can use AIG models for the traffic it injects. You don't need to run AIG's own traffic injector alongside BeyondATC.

**Author:** the AIG team · **Support:** via the AIG forum and Discord
